# ADR-0007: Settings in one JSON file with a generated schema

**Status:** Accepted (confirmed against spec.md §4; real-hardware validation tracked in Phase 0 spikes).

## Context

The owner wants one hand-editable settings file (FR-MOD-2).

## Decision

config.json plus config.schema.json generated by schemars. Secrets go in Credential Manager; learned data in state.json.

## Consequences

Editors give completion and validation. The file is safe to share.
