# ADR-0010: Svelte 5 + TypeScript UI

**Status:** Accepted (confirmed against spec.md §4; real-hardware validation tracked in Phase 0 spikes).

## Context

Window-open memory should stay low and code must be reviewable.

## Decision

Svelte 5, TypeScript strict, Vite; typed bindings generated by tauri-specta.

## Consequences

Small bundles; UI and core cannot silently drift apart.
